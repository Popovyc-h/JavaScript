    Вступ до об'єктної моделі документа

    DOM представляє HTML-документ як ієрархічне дерево вузлів.

    DOM дозволяє JavaScript динамічно змінювати контент сторінки.

    Навігація по елементах дерева

    Для переходу між елементами використовуються навігаційні властивості. Детальніше у внутрішній документації або на зовнішньому порталі MDN.

    Методи внесення змін у документ

    Сучасні методи дозволяють зручно вставляти вузли: append, prepend, after, before. Також перегляньте підручник з JavaScript.
